\begin{abstract}
Long-term agents can retrieve a fact that is relevant yet ineligible under the
current principal, purpose, or time.  We present a stagewise eligibility-enforcement
evaluation: a query-conditioned, three-valued retrieval-admissibility target,
matched-recall risk with unresolved-label bounds, and record-level observability at
retrieval, prompt exposure, and answer disclosure.  On frozen rankings over
\NaturalQueryCount{} public-source queries, trusted namespace support improves
top-20 recall from \TopTwentyGlobalRecall{} to \TopTwentyNamespaceRecall{} while
reducing penalized admissibility upper risk from \TopTwentyGlobalAdmRisk{} to
\TopTwentyNamespaceAdmRisk{}.  Across the tested corruption mechanisms, released
policy metadata drives the incremental gain, the evaluated coarse lifecycle-only
rule over-filters, and false-deny errors cross their channel-specific utility--risk
boundary earlier than fail-open errors.  On 72 fixed public-development cases,
released fields expose
risk headroom (\ReleasedOracleAdmRiskDelta{}, 95\% CI
\ReleasedOracleAdmRiskDeltaCI{}) that text-only verifiers do not recover without
rejecting stable evidence.  In separate constructed exposure executions, each reader
is reported separately: all have positive selectivity-gap intervals, while only
DeepSeek has a strictly positive relevant-inadmissible exposure-effect interval; the
independent Claude estimate is positive but includes zero.  Across these stagewise
tests, gains appear only when reliable eligibility information constrains candidates
before prompt assembly.  We contribute an auditable evaluation protocol and
failure-mechanism diagnosis, not a new memory index or a production-safety claim.
\end{abstract}

\section{Introduction}

Long-term agents do not only fail by forgetting.  They can retrieve the right fact
under the wrong authority, purpose, or time.  The dangerous record is often highly
relevant: an earlier delivery address answers an address question, another user's
market note answers a market question, and a superseded date answers a date question.
Semantic ranking alone cannot establish whether any of those records may influence
the current answer.

Figure~\ref{fig:pipeline} isolates the eligibility gap with three audited failures.
A market memory can belong to the wrong principal, an earlier Lisbon date can be
superseded for a current-state query, and a phone detail can remain topically similar
after an explicit forget request.  Admissibility therefore belongs to the memory--
query context, not to the record alone.  We represent that context using authenticated
scope, governing policy, query intent, and time, while retaining an unresolved state
when released evidence does not establish a verdict.  We then record each memory ID
at the stored, retrieved, verified, exposed, and disclosed stages.  The intended
enforcement boundary lies before prompt assembly, not inside the reader.

This paper asks three linked questions.  \emph{Support:} do trusted constraints
improve retrieval rather than merely hiding errors?  \emph{Verification:} when
eligibility metadata is unreliable or absent, can a text-only LLM reconstruct it
without rejecting stable evidence?  \emph{Enforcement:} if an inadmissible record
reaches the prompt, can reader restraint prevent disclosure?  Together these
stagewise tests examine one enforcement sequence: candidate support, metadata
reliability, selective verification, prompt exposure, and answer disclosure.  They
use distinct populations and estimands and do not constitute one end-to-end causal
estimate.

Prior work already establishes that relevance is insufficient.  RaMem restores
episodic conditions for validity-aware retrieval \citep{yang2026ramem}; GateMem tests
utility, access control, and active forgetting \citep{ren2026gatemem}; and Governed
Shared Memory formalizes scoped retrieval, supersession, provenance, and policy-
governed propagation as system primitives \citep{margalit2026governed}.  Our claim is
therefore narrower: we provide a common measurement layer and an empirical
decomposition of where eligibility enforcement succeeds and fails.

Our contributions are:
\begin{itemize}
  \item \textbf{Measurement:} a stagewise eligibility-enforcement evaluation with a
  three-valued admissibility target, matched-recall risk bounds under unresolved
  labels, and a retrieval-to-disclosure audit;
  \item \textbf{Natural diagnosis:} a hash-bound audit of support gains, policy versus
  lifecycle attribution, and asymmetric failure under metadata corruption; and
  \item \textbf{Enforcement diagnosis:} oracle--inference and stable-overflip tests,
  followed by a paired prompt-exposure intervention across separately reported
  readers and an independently executed replication.
\end{itemize}

\section{Related Work}

\paragraph{Long-term memory evaluation.}
LongMemEval evaluates extraction, multi-session reasoning, temporal reasoning,
updates, and abstention, while LongMemEval-V2 extends evaluation to environment
experience and context gathering \citep{wu2025longmemeval,wu2026longmemevalv2}.
RHELM studies heterogeneous, evolving histories and MemOps evaluates explicit
remember, forget, update, and reflection operations
\citep{zhang2026rhelm,hao2026memops}.  These benchmarks motivate our record-level
treatment of evidence state and provenance.

\paragraph{Governance and contextual validity.}
GateMem evaluates access control and active forgetting; Collaborative Memory
implements dynamic asymmetric access policies with private/shared memory tiers and
persistent provenance; CIMemories tests contextual information flow; and STALE
studies invalidated premises
\citep{ren2026gatemem,rezazadeh2025collaborative,
mireshghallah2026cimemories,chao2026stale}.  CIMemories also documents
all-or-nothing prompt-level sharing under privacy-conscious prompting; our controlled
candidate-level diagnostic localizes an analogous false-denial failure before prompt
assembly and connects it to route utility.  RaMem restores episodic conditions for
validity-aware retrieval, while Governed Shared Memory implements scoped retrieval,
supersession, provenance, and policy-governed propagation in a live service
\citep{yang2026ramem,margalit2026governed}.  We therefore do not claim to introduce
governance-aware retrieval.  Our contribution is a common, uncertainty-aware
evaluation of eligibility evidence and its failure boundaries from candidate support
to prompt disclosure.  These systems optimize answer- or service-level objectives,
whereas our primary outcomes are record-level eligibility, matched-recall risk,
prompt exposure, and disclosure; nominal score comparisons would not share an
estimand.

\paragraph{Access control around retrieval and generation.}
Attribute-based access control (ABAC) supplies a general vocabulary for evaluating
requests against subject, object, action, and environment attributes
\citep{hu2019abac}.  Recent agent systems instantiate related controls at different
boundaries.  Securing the Agent applies vendor-neutral ABAC gates to multitenant
retrieval and tool use, explicitly separating relevance from authorization
\citep{arceo2026securing}; SD-RAG applies sanitization and disclosure controls during
retrieval, before the model input is augmented \citep{almasoud2026sdrag}.  Our novelty is not
the placement of another enforcement point.  It is the joint evaluation of candidate
support, metadata reliability, selective verification, prompt exposure, and answer
disclosure with unresolved-label bounds and stage-specific estimands.

\paragraph{Analytical agent evaluation.}
AgentBench and AgentBoard broaden agent evaluation beyond static language tasks
\citep{liu2024agentbench,ma2024agentboard}; HELM emphasizes multi-metric transparent
evaluation \citep{liang2023helm}.  Our protocol follows this analytical stance:
final-answer accuracy alone cannot tell whether an answer was supported by
admissible evidence.  Because model-based evaluation can introduce systematic
biases \citep{liu2023geval}, we report reader identities separately and do not pool
their estimates.

\section{Retrieval Admissibility Methodology}

Our contribution is a stagewise eligibility-enforcement evaluation, not a latent-
state classifier or a new index.  It formalizes the eligibility decision, compares
routes at matched evidence recall, and identifies where a memory crosses the prompt
boundary.

\subsection{Evidence eligibility is query-conditioned}

Let $z=(q,p,\rho,t)$ contain the query, authenticated principal, governing policy,
and time.  For memory $m$, the evaluator records relevance $r_z(m)$, namespace or
scope membership $n_z(m)$, policy permission $g_z(m)$, and lifecycle compatibility
$\ell_z(m)$.  Each axis lies in $\mathcal{T}=\{1,0,?\}$: established positive,
established negative, or unresolved.  The conservative conjunction is
\begin{equation}
\bigwedge\nolimits_{3}(x_1,\ldots,x_d)=
\begin{cases}
0, & \exists j:x_j=0,\\
1, & \forall j:x_j=1,\\
?, & \text{otherwise}.
\end{cases}
\label{eq:three-valued}
\end{equation}
We define admissibility and usability for the memory--context pair as
\begin{align}
a_z(m)&=\bigwedge\nolimits_{3}\!\left(n_z(m),g_z(m),\ell_z(m)\right),
\label{eq:admissible}\\
u_z(m)&=\bigwedge\nolimits_{3}\!\left(r_z(m),a_z(m)\right).
\label{eq:usable}
\end{align}
Thus one established governance violation excludes a candidate, usability requires
relevance and admissibility, and missing evidence never becomes an implicit pass.
With complete binary labels, this reduces to
$\mathcal{U}_z=\mathcal{R}_z\cap\mathcal{N}_z\cap\mathcal{P}_z\cap\mathcal{L}_z$.
Lifecycle compatibility remains relational: a superseded value may be excluded for
``what is current?'' and retained for ``how did it change?''  The released mapping is
specified in Appendix~\ref{app:metric-details}; it is not a claim that latent state
or intent can be inferred from text.

\subsection{Verification precedes exposure}

For every returned ID, the verifier emits $u_z(m)$, known exclusion reasons, and
unresolved status.  Trusted namespace metadata may constrain ranking support from
the global store $\mathcal{M}$ to
$\mathcal{C}^{N}_z=\{m\in\mathcal{M}:n_z(m)=1\}$.  The protocol never silently
completes missing provenance.  For route $a$, $S_m$, $R_{qma}$, and $E_{qma}$ denote
stored, returned, and prompt-exposed records, with
$E_{qma}\leq R_{qma}\leq S_m$.  We separately record $Y_{qa}$, whether the protected
target appears in the answer.  These logs localize enforcement failure without
claiming access to the reader's internal use of evidence.

\subsection{Matched-recall risk preserves utility and uncertainty}
\label{sec:matched-risk}

Let $\mathcal{G}_q$ be known usable anchors and
$\pi_{qa}=(m_1,\ldots,m_n)$ a ranked route.  At target recall $\tau$, we score the
smallest qualifying prefix
\begin{equation}
k^*_{qa}(\tau)=\min\left\{k:
\frac{|\{m_1,\ldots,m_k\}\cap\mathcal{G}_q|}{|\mathcal{G}_q|}\geq\tau\right\},
\qquad P_{qa}(\tau)=\{m_1,\ldots,m_{k^*_{qa}(\tau)}\}.
\label{eq:matched-prefix}
\end{equation}
This charges a route for every item ranked before it reaches the same anchor-recall
target.  In a prefix of size $N$, let $c^B$, $v^B$, and $h^B$ count negative,
positive, and unresolved labels for status family $B\in\{U,A\}$, where $U$ denotes
usability and $A$ admissibility.  We report
\begin{equation}
C^{K,B}=\frac{c^B}{c^B+v^B},\qquad
\gamma^B=\frac{c^B+v^B}{N},\qquad
[C^{L,B},C^{U,B}]=\left[\frac{c^B}{N},\frac{c^B+h^B}{N}\right].
\label{eq:matched-bounds}
\end{equation}
The interval is sharp under the released labels and has width $1-\gamma^B$.
Infeasible routes receive upper risk 1 rather than appearing safe.  The historical
selection score remains \emph{penalized non-usable upper risk}; the post-hoc v2 score
is \emph{penalized admissibility upper risk}.  We never rename or pool them.  Full
aggregation is specified in Section~4.3; the infeasibility decomposition and
edge-case conventions appear in Appendix~\ref{app:metric-details}.

\subsection{Exposure and disclosure}

The observational GateMem audit compares exposure-discordant routes but is explicitly
non-causal (Appendix~\ref{app:gatemem}).  The controlled experiment fixes query and
background candidates and changes only whether one candidate is exposed.  For paired
unit $i$ in relevance--admissibility cell $c$, let $D_i(1)$ and $D_i(0)$ denote
literal target disclosure when exposed and withheld.  We estimate
\begin{equation}
\hat{\Delta}_c=\frac{1}{n_c}\sum_{i\in c}\bigl[D_i(1)-D_i(0)\bigr],\qquad
\hat{S}=\hat{\Delta}_{\mathrm{rel,adm}}-
\hat{\Delta}_{\mathrm{rel,inadm}}.
\label{eq:paired-exposure}
\end{equation}
The selectivity gap $\hat S$ asks whether exposure enables relevant admissible
evidence more than relevant inadmissible evidence.  It identifies a prompt-level
effect in the constructed population, not internal model use or natural prevalence.

\subsection{Datasets and splits}

The natural retrieval audit combines public RHELM conversation histories and MemOps
profiles and operation traces \citep{zhang2026rhelm,hao2026memops}.  Development has
23 disjoint persona/profile groups, 45,978 memories, and 1,104 queries; evaluation has
\NaturalGroupCount{} groups, \NaturalMemoryCount{} memories, and
\NaturalQueryCount{} queries.  For RHELM, a query can retrieve only turns strictly
earlier than its date; for MemOps, every method-visible dialogue memory in the split
is eligible for global retrieval.  Namespace support then restricts candidates to the
query persona or profile.  Released evidence IDs, provenance, and deterministic
operation replay provide relevance anchors and governance states.  We use no
candidate subsampling, positive injection, or human-overlap label.

The text-verification diagnostic is a stable-hash sample of 96 public-development
queries: 32 RHELM current-state, 32 MemOps current-state, and 32 MemOps history
queries.  Eight cases per stratum select thresholds and 24 per stratum form the 72-case
analysis set.  A separate constructed diagnostic contains four scenarios for each of
principal scope, policy purpose, lifecycle intent, and as-of time.  Each scenario has
two paraphrased query pairs over a fixed three-candidate pool.  The paired exposure
experiment reuses those governing conditions with independently frozen relevance and
admissibility labels.  These diagnostic populations are not estimates of natural
prevalence.

\subsection{Models and comparison systems}

All dense retrieval arms use the pinned \texttt{Qwen/Qwen3-Embedding-8B} snapshot:
4,096-dimensional float32 vectors, a 512-token maximum, unit-normalized last-token
pooling, exact inner product, and stable memory-ID tie breaking.  The nine
development-selected arms are global BM25, global dense, BM25--dense reciprocal-rank
fusion, recency-augmented dense, namespace dense, query-agnostic current-only,
historical released-field v1, a threshold router, and a cluster router.  The primary
v2 support analysis holds the global- and namespace-dense rankings fixed across four
budgets; policy-only, lifecycle-only, and combined released-governance filters are
untuned attribution diagnostics.  Appendix~\ref{app:arms} gives the exact model
revision, scoring equations, and selected settings.

Natural text verification compares the fixed namespace-dense top-20 pool with a
released-field oracle, a thresholded text filter, and an abstaining variant using
complete outputs from \texttt{gpt-5.6-sol} and \texttt{gemini-3.6-flash}.  The
models receive only query text and visible time plus candidate key, rank, text, and
visible order.  Source and namespace IDs, required-evidence labels, released intent,
policy, lifecycle, distractor labels, embeddings, and scorer metadata remain hidden.
On the 24 calibration cases, model-specific violation thresholds---and the unknown
cutoff for the abstaining arm---are selected from frozen grids to maximize known-
violation recall subject to at most 1\% required-anchor false denial, followed by
precision, false-denial, threshold, and unknown-cutoff tie-breaks.  The selected
operating points are then frozen for the 72 analysis cases.  GPT-5.6 uses low effort
and Gemini uses low thinking for this diagnostic.  The direct and abstaining routes
select the same candidates at the resulting cutoffs; we retain both names to expose
the preregistered comparison rather than count them as independent evidence.

The controlled verifier and paired-exposure panels also include
\texttt{deepseek-v4-pro}.  Each model sees the same semantic task contract; provider
adapters do not change its meaning, and only complete bundles enter a comparison.
The paired-exposure configurations use reasoning \texttt{none} for GPT-5.6 Sol,
thinking \texttt{minimal} for Gemini 3.6 Flash, and disabled thinking for DeepSeek V4
Pro.  A separately hash-bound fourth-reader replication uses
\texttt{claude-opus-5} with disabled thinking and medium effort.  It reuses the same
construction but is not pooled with or retroactively inserted into the original
three-reader execution.  Every reader contributes one accepted response per request,
with no judge, semantic repair, selective rerun, or cross-model pooling.

\subsection{Metrics}

Natural retrieval is macro-averaged within source and then equally across RHELM and
MemOps.  Let $\langle\cdot\rangle_{\mathcal S}$ denote this equal-source operator,
and let $F_{qa}$ indicate that route $a$ reaches target recall $.8$ for query $q$.
For status family $B\in\{U,A\}$---usability or admissibility---we define
\begin{equation}
\widetilde C^{U,B}_{qa}
=\begin{cases}
C^{U,B}_{qa},&F_{qa}=1,\\
1,&F_{qa}=0,
\end{cases}
\qquad
\operatorname{PCR}^{B}_{a}
=\left\langle\widetilde C^{U,B}_{qa}\right\rangle_{\mathcal S}.
\label{eq:penalized-risk}
\end{equation}
We report evidence recall, feasible rate, and $\operatorname{PCR}^{A}$ as primary
retrieval outcomes; $B=U$ names the frozen historical selection family.  Typed
scope, policy, and lifecycle violations are reported separately.

Candidate-level verifier diagnostics include balanced accuracy, Brier score,
calibration error, violation precision and recall, coverage, and required-anchor
false denial.  Controlled verification reports focal consistency and stable
overflip; paired exposure uses Equation~\ref{eq:paired-exposure}.  Appendix
\ref{app:metric-details} gives the exact definitions, undefined-denominator rules,
risk decomposition, and edge cases.

\subsection{Selection, uncertainty, and boundaries}

A 165-setting retrieval grid is selected on development only using a lexicographic
objective: maximize feasible rate, minimize historical v1 penalized non-usable upper
risk, then break ties by known-label risk, recall, work, and stable setting ID.  The
\NaturalRouteRows{} evaluation routes receive no retuning or repair.  Corrected v2
results are post-hoc re-scores of frozen rankings, and the released-governance v2
oracle receives no tuning.  Metadata corruption changes only method-visible fields;
labels, embeddings, dense scores, and retrieval settings remain fixed.  Each channel
uses nested rates $\{0,.02,.05,.10,.20,.30,.40,.50\}$ over ten seeds; support-expanding
errors rerank the resulting candidate set.  A dominance break is an adjacent observed
grid bracket, not an interpolated population threshold.

At each corruption rate, an arm \emph{weakly dominates} its reference when feasible
rate is no lower and penalized admissibility upper risk is no higher; equality is
allowed.  Namespace-corruption arms use global dense as their reference.  Policy,
lifecycle, and intent corruptions use clean namespace dense.  Recall, typed
violations, and candidates scored are diagnostics, not dominance criteria.

All reported intervals are pointwise 95\% percentile bootstrap intervals from
10,000 replicates; no simultaneous-coverage claim is made.  Fixed-budget natural
contrasts and released-field attribution resample namespace groups while preserving
equal-source macro-averaging.  Text verification resamples namespace groups
stratified by source and query intent.  Controlled verification and exposure
resample the 16 scenarios within governing-axis strata.  Corruption means are
descriptive over ten seeds.  The
natural run has no downstream reader, models and experimental populations are never
pooled, and none of these results is an official RHELM, MemOps, or GateMem benchmark
score.  Appendices~\ref{app:gatemem} and \ref{app:smoke} retain the secondary
observational GateMem audit \citep{ren2026gatemem} and implementation smoke.

\subsection{Support constraints improve the utility--risk frontier}

The namespace advantage is already visible at top-20, not only top-100
(Figure~\ref{fig:constraint-reliability}a).  Recall rises from
\TopTwentyGlobalRecall{} to \TopTwentyNamespaceRecall{} (difference
\TopTwentyRecallDelta{}, 95\% CI \TopTwentyRecallDeltaCI{}), feasible rate from
\TopTwentyGlobalFeasible{} to \TopTwentyNamespaceFeasible{}
(\TopTwentyFeasibleDelta{}, \TopTwentyFeasibleDeltaCI{}), and penalized
admissibility upper risk falls from \TopTwentyGlobalAdmRisk{} to
\TopTwentyNamespaceAdmRisk{} (difference \TopTwentyAdmRiskDelta{},
\TopTwentyAdmRiskDeltaCI{}).  At top-100 the respective deltas are
\TopHundredRecallDelta{}, \TopHundredFeasibleDelta{}, and
\TopHundredAdmRiskDelta{}.  Every interval at all four tested budgets excludes zero.

Namespace support also reduces mean candidate scoring from
\GlobalDenseCandidates{} to \NamespaceDenseCandidates{} records per query, a
\CandidateWorkRatio{}$\times$ reduction.  This is a deterministic retrieval-work
diagnostic under exact search, not a wall-clock or production-latency claim.

The risk decomposition prevents a feasibility gain from masquerading as cleaner
feasible prefixes.  At top-100, the total \TopHundredAdmRiskDelta{} difference is the
sum of an infeasibility component \TopHundredInfeasibilityDelta{} and a
feasible-prefix admissibility component \TopHundredConditionalAdmDelta{}; both
intervals exclude zero.  These are post-hoc v2 scores on frozen rankings.  The
historical preregistered v1 result remains the penalized \emph{non-usable} upper risk
and is reported separately in Appendix~\ref{app:arms}.

\subsection{Metadata error direction determines whether constraints remain useful}

Corrected attribution changes the earlier lifecycle interpretation
(Figure~\ref{fig:constraint-reliability}b).  Policy-only filtering changes recall by
\PolicyOnlyRecallDelta{} (\PolicyOnlyRecallDeltaCI{}), feasible rate by
\PolicyOnlyFeasibleDelta{} (\PolicyOnlyFeasibleDeltaCI{}), and admissibility risk by
\PolicyOnlyAdmRiskDelta{} (\PolicyOnlyAdmRiskDeltaCI{}).  Lifecycle-only filtering
instead changes recall by \LifecycleOnlyRecallDelta{} and risk by
\LifecycleOnlyAdmRiskDelta{}: the evaluated two-intent rule removes useful evidence.
The corrected combined v2 arm remains beneficial, but less so than policy alone.
Thus the incremental gain is policy-driven, not lifecycle-only headroom.

Corruption confirms that error direction matters, but only relative to each channel's
declared reference.  Against global dense, namespace false denial, missing labels,
and source-level label swaps remain weakly dominant through .10 and first fail at
.20.  At the swap failure point, recall is \NamespaceSwapTwentyRecall{} and feasible
rate is \NamespaceSwapTwentyFeasible{}.  Namespace false allow remains weakly
dominant through .50, but this aggregate verdict is not safety: at .50 its matched-
prefix wrong-scope exposure is \FalseAllowHalfWrongScope{} and it scores
\FalseAllowHalfCandidates{} candidates per query, versus roughly 1,551 when clean.
Against clean namespace dense, policy false denial and lifecycle false-stale fail at
the first nonzero .02 point, whereas policy false allow and fail-open missing pass
through .30 and first fail at .40.  These channel-specific observed brackets are not
universal metadata-accuracy thresholds.

\subsection{Text-only verifiers over-deny stable evidence on fixed candidates}

The released oracle preserves recall and feasibility while reducing admissibility
risk by \ReleasedOracleAdmRiskDelta{} (\ReleasedOracleAdmRiskDeltaCI{};
Figure~\ref{fig:inference-gap}a).  GPT-5.6 text filtering instead changes recall by
\OpenAIInferredRecallDelta{} (\OpenAIInferredRecallDeltaCI{}), feasible rate by
\OpenAIInferredFeasibleDelta{} (\OpenAIInferredFeasibleDeltaCI{}), and risk by
\OpenAIInferredAdmRiskDelta{} (\OpenAIInferredAdmRiskDeltaCI{}).  Gemini does not
realize the oracle benefit either: its recall, feasibility, and risk differences are
\GeminiInferredRecallDelta{}, \GeminiInferredFeasibleDelta{}, and
\GeminiInferredAdmRiskDelta{}.  The models occupy different classification operating
points (Appendix Table~\ref{tab:text-inference-diagnostics}), but neither converts
released-field headroom into a utility-preserving route.

Controlled pairs expose the mechanism (Figure~\ref{fig:inference-gap}b).  GPT-5.6
and Gemini classify all focal flips correctly, while DeepSeek reaches
\DeepSeekControlledFocalConsistency{}.  Yet stable-control overflip is
\GPTControlledOverflip{}, \GeminiControlledOverflip{}, and
\DeepSeekControlledOverflip{}, all above the frozen .05 ceiling.  Post-hoc errors are
dominated by false denial of stable-admissible memories
(\GPTControlledStableFalseDeny{}, \GeminiControlledStableFalseDeny{}, and
\DeepSeekControlledStableFalseDeny{}) rather than false admission of stable-
inadmissible controls.  Strong focal rule-following therefore does not establish
selective verification.

\subsection{Once exposed, inadmissible evidence can reach the answer}

Each of the three original readers has a positive selectivity-gap interval
(Figure~\ref{fig:paired-exposure}).  DeepSeek alone has a strictly positive
relevant-inadmissible exposure effect, \DeepSeekExposureInadmissible{}
(\DeepSeekExposureInadmissibleCI{}), showing that reader selectivity does not
eliminate constructed prompt-level disclosure after exposure.  The independently
executed Claude Opus 5
replication also yields a positive selectivity gap, \OpusExposureGap{}
(\OpusExposureGapCI{}), but its relevant-inadmissible interval
\OpusExposureInadmissibleCI{} includes zero and therefore does not establish a
nonzero relevant-inadmissible effect.  All estimates remain reader-specific; the
intervention
identifies prompt-level disclosure effects under constructed query conditions, not
internal model use or an isolated causal moderator effect of admissibility.

\paragraph{Secondary diagnostics.}
The frozen threshold arm loses recall and the cluster arm is practically
indistinguishable from namespace dense (Appendix Figure~\ref{fig:retrieval}).
Observational GateMem traces associate exposure with disclosure and expose a
leakage--utility--over-refusal trade-off (Appendix Figure~\ref{fig:gatemem-observational});
they are not pooled with the natural or controlled experiments.

\section{Discussion}

\paragraph{Authenticate before ranking.}
Semantic sophistication cannot repair a misspecified evidence universe.  When
principal and provenance are authenticated, impossible candidates should leave the
support before semantic ranking.  Our result does not endorse arbitrary hard filters:
policy supplied the measured gain, while the coarse lifecycle rule over-filtered.

\paragraph{Preserve unknown rather than defaulting to deny.}
``Metadata accuracy'' is not one scalar.  False denial removes required evidence
before fail-open errors erase aggregate dominance, while fail-open errors continue to
expand exposure and work.  Text-only verifiers reproduce this asymmetry by rejecting
stable admissible candidates.  Unknown state should therefore remain explicit and
auditable rather than silently becoming either permission or denial.

\paragraph{Enforce before prompt assembly.}
In the constructed exposure test, reader selectivity did not eliminate disclosure
for every reader once a relevant inadmissible record crossed the prompt boundary.
The supported engineering pattern is staged: authenticated metadata constrains
support; a three-valued verifier records exclusions and unknowns;
semantic ranking and prompt assembly operate on the resulting candidates; and the
reader remains auditable but does not carry policy enforcement.

These evaluations identify successive failure boundaries but do not estimate the
full retrieval-to-disclosure effect on one natural population.

\section{Limitations and Broader Impact}

The natural audit covers two public-source families, uses released metadata, and has
no downstream reader.  Corruptions are controlled mechanisms; their grid brackets
are not population thresholds.  V2 scoring is post-hoc on frozen rankings, whereas
selection used v1 non-usable risk.  Policy is a released approximation, lifecycle has
two intents, candidate counts are not production cost, and the natural and controlled
inference populations contain only 72 cases and 16 scenarios, respectively.

GateMem is observational, same-provider, and uses distinct utility and leakage
populations.  Paired exposure uses constructed queries, literal markers, and a
rule-based scorer; it does not isolate admissibility from all query changes or measure
internal use or natural prevalence.  The Claude estimate is a separately executed
replication and is not pooled with the original three-reader panel; the heterogeneous
reader controls do not define a capability leaderboard.  Filters can suppress
legitimate evidence, so deployments should log exclusions and evaluate matched-recall
utility.  We release only content-free aggregates and hashes, not conversations,
responses, or private data.

\section{Conclusion}

Across separate stagewise populations, trusted support improves retrieval when
eligibility metadata is reliable, while text-only verification over-denies stable
evidence and constructed exposure produces literal-marker disclosure in some reader
conditions.  The contribution is a stagewise, uncertainty-aware, matched-utility
evaluation of these enforcement boundaries, supporting authenticated verification
before prompt assembly rather than another semantic-ranking layer.

\section{Metric Details}
\label{app:metric-details}

For status family $B\in\{U,A\}$, the matched-prefix quantities in
Equation~\ref{eq:matched-bounds} obey
\begin{align}
C^{K,B}_{qa}&=\frac{c^B}{c^B+v^B}, &
\gamma^B_{qa}&=\frac{c^B+v^B}{N},\label{eq:known-coverage}\\
C^{L,B}_{qa}&=\frac{c^B}{N}=\gamma^B_{qa}C^{K,B}_{qa}, &
C^{U,B}_{qa}&=\frac{c^B+h^B}{N}
=\gamma^B_{qa}C^{K,B}_{qa}+(1-\gamma^B_{qa}).
\label{eq:partial-id}
\end{align}
Hence $C^{U,B}_{qa}-C^{L,B}_{qa}=1-\gamma^B_{qa}$.  The bounds are obtained by
assigning every unresolved item first to the positive and then to the negative class;
if every item is unresolved, $C^{K,B}$ is undefined but the interval remains $[0,1]$.

The aggregate in Equation~\ref{eq:penalized-risk} decomposes exactly within each
source.  Writing $\operatorname{PCR}^{B}_{as}$ for the source-$s$ term, we have
\begin{equation}
\operatorname{PCR}^{B}_{as}
=\underbrace{\frac{1}{|\mathcal{Q}^{+}_s|}\sum_{q\in\mathcal{Q}^{+}_s}(1-F_{qa})}_{\text{infeasibility}}
+\underbrace{\frac{1}{|\mathcal{Q}^{+}_s|}\sum_{q\in\mathcal{Q}^{+}_s}
F_{qa}C^{U,B}_{qa}}_{\text{feasible-prefix contribution}}.
\label{eq:risk-decomposition}
\end{equation}
The reported $\operatorname{PCR}^{B}_{a}$ is the equal-source mean of these terms.
Queries without known anchors are recall-unevaluable rather than assigned zero.

\paragraph{Retrieval and verifier diagnostics.}
Let $\mathcal Q_s^+$ be recall-evaluable queries from source $s$, with
$\mathcal S=\{\mathrm{RHELM},\mathrm{MemOps}\}$.  The equal-source macro operator,
evidence recall, feasibility, and typed violation rate are
\begin{align}
\langle X\rangle_{\mathcal S}
&=|\mathcal S|^{-1}\sum_{s\in\mathcal S}|\mathcal Q_s^+|^{-1}
  \sum_{q\in\mathcal Q_s^+}X_q,\\
\operatorname{Rec}_{qa}(k)
&=\frac{|\{m_1,\ldots,m_k\}\cap\mathcal G_q|}{|\mathcal G_q|},\qquad
F_{qa}=\mathbf 1\{\operatorname{Rec}_{qa}(n_{qa})\geq .8\},
\label{eq:retrieval-outcomes}\\
V^{(j)}_{qa}
&=|P_{qa}|^{-1}\sum_{m\in P_{qa}}\mathbf 1\{x_{zj}(m)=0\},\qquad
x_{zj}\in\{n_z,g_z,\ell_z\}.
\label{eq:typed-violation}
\end{align}
Among $M$ verifier candidates, let $\mathcal K$ index the $M_K$ known labels;
$y_i\in\{0,1\}$ and $p_i$ are the violation label and probability, and $I_b$ are
ten equal-width probability bins.  Indicators $d_i,k_i,v_i,r_i,c_i$ mark dropped,
known-label, known-violation, required-anchor, and covered status.  We use
\begin{align}
\operatorname{BA}
&=\tfrac12(\operatorname{TPR}+\operatorname{TNR}), &
\operatorname{Brier}
&=M_K^{-1}\sum_{i\in\mathcal K}(p_i-y_i)^2,\\
\operatorname{ECE}_{10}
&=\sum_b\frac{|I_b|}{M_K}|\bar y_b-\bar p_b|, &
\operatorname{Prec}_{V}
&=\frac{\sum_i d_iv_i}{\sum_i d_ik_i},
\label{eq:verification-calibration}\\
\operatorname{Rec}_{V}
&=\frac{\sum_i d_iv_i}{\sum_i v_i}, &
\operatorname{Cov}
&=M^{-1}\sum_i c_i,\qquad
\operatorname{FD}=\frac{\sum_i d_ir_i}{\sum_i r_i}.
\label{eq:filter-diagnostics}
\end{align}
For $J$ controlled focal pairs, let $\hat a^f_{\nu,+/-}$ be the focal argmax and
$\mathcal H_\nu$ its stable controls.  Focal consistency and stable overflip are
\begin{align}
\operatorname{FC}
&=J^{-1}\sum_{\nu=1}^{J}
  \mathbf 1\{\hat a^f_{\nu,+}=1\land\hat a^f_{\nu,-}=0\},\\
\operatorname{OF}
&=\frac{\sum_{\nu=1}^{J}\sum_{h\in\mathcal H_\nu}
  \mathbf 1\{\hat a^h_{\nu,+}\neq\hat a^h_{\nu,-}\}}
  {\sum_{\nu=1}^{J}|\mathcal H_\nu|}.
\label{eq:controlled-verification}
\end{align}
Unknown is a distinct argmax state; undefined denominators remain unavailable.

For the observational GateMem audit, let $X_{qa}$ indicate target exposure and
$Y_{qa}$ target disclosure.  For each checkpoint, form ordered discordant pairs
$D_q=\{(a,b):X_{qa}=1,\ X_{qb}=0\}$ and average first within checkpoint, then across
checkpoints:
\begin{equation}
d_q=\frac{1}{|D_q|}\sum_{(a,b)\in D_q}(Y_{qa}-Y_{qb}),\qquad
\widehat{\mathrm{RD}}=\frac{1}{|\mathcal{Q}_D|}
\sum_{q\in\mathcal{Q}_D}d_q.
\label{eq:discordant-rd}
\end{equation}
This prevents checkpoints with more route pairs from receiving more weight; it does
not make the route contrast causal.

For completeness, the released-field lifecycle rule used in Section~3.1 is
\begin{equation}
\ell_z(m)=
\begin{cases}
1, & s_m=\text{current},\\
1, & s_m\in\{\text{stale},\text{superseded}\},\ i_q=\text{history},\\
0, & s_m\in\{\text{stale},\text{superseded}\},\ i_q=\text{current},\\
?, & s_m=\text{unknown}\ \text{or}\ i_q=\text{unknown}.
\end{cases}
\label{eq:lifecycle}
\end{equation}
Writing $x_{zj}(m)$ for the recorded label on admissibility axis $j$, the verifier's
known exclusion reasons and trusted-namespace support are
\begin{align}
\operatorname{reason}_z(m)
&=\{j\in\{\mathrm{scope},\mathrm{policy},\mathrm{lifecycle}\}:x_{zj}(m)=0\},
\label{eq:reasons}\\
\mathcal{C}^{N}_z&=\{m\in\mathcal{M}:n_z(m)=1\},\qquad
\pi^{N}_z=\operatorname{Rank}(q;\mathcal{C}^{N}_z).
\label{eq:namespace-support}
\end{align}
The typed violation metric is defined in Equation~\ref{eq:typed-violation}.
Finally, for leakage, utility, or refusal outcome $j$ and its own eligible population
$\mathcal{Q}_j$, the strict-minus-base contrast is
\begin{equation}
\Delta_j=\frac{1}{|\mathcal{Q}_j|}\sum_{q\in\mathcal{Q}_j}
\left(Y^{(j)}_{q,\mathrm{strict}}-Y^{(j)}_{q,\mathrm{base}}\right).
\label{eq:safety-utility}
\end{equation}

For a matched prefix, a known-rate estimate is undefined when every status in its
chosen family is unresolved; the lower and upper bounds remain defined.  Queries with no known usable anchors are
excluded from recall averages, and the evaluable rate is reported separately.  Macro
averages never impute missing query metrics.  Duplicate ranked memory identifiers,
missing assessments, negative runtime measurements, and non-finite values are
rejected by the reference implementation.

\section{Natural-Corpus Construction and Arms}
\label{app:arms}

RHELM development uses the first three persona-hash groups; evaluation uses the
remaining seven.  For each query, only conversation turns strictly earlier than its
date are candidates.  MemOps development uses the first 20\% of profile-hash groups;
evaluation uses the remaining 80 profiles.  Every method-visible dialogue memory in
the split is a global candidate.  MemOps has no cross-case wall clock, so its recency
arm uses released source order and is not a temporal-freshness claim.

All dense arms use \texttt{Qwen/Qwen3-Embedding-8B} at revision
\nolinkurl{1d8ad4ca9b3dd8059ad90a75d4983776a23d44af}, maximum length 512,
unit-normalized last-token pooling, float32 vectors, exact inner product, and stable
memory-ID tie breaking.  For unit vectors,
\[
s_{\mathrm{dense}}(m,q)=e_m^\top e_q.
\]
The hybrid arm uses reciprocal-rank fusion
\[
s_{\mathrm{RRF}}(m,q)=
\frac{1}{60+\operatorname{rank}_{\mathrm{BM25}}(m)}
+
\frac{1}{60+\operatorname{rank}_{\mathrm{dense}}(m)},
\]
and the recency control uses
$s_{\mathrm{rec}}(m,q)=s_{\mathrm{dense}}(m,q)+\gamma\rho(m)$, where
$\rho(m)\in[0,1]$ is normalized released order.

The threshold router incrementally assigns a memory to its most similar namespace
centroid when $\max_k\cos(e_m,c_k)\geq\theta$ and otherwise creates a cluster.  At
query time it selects at most $L$ centroids above $\theta$.  The cluster router uses
\[
\ell_k(x)=\gamma\log(n_k+\beta)+\frac{\cos(x,c_k)}{\tau},
\qquad
\ell_{\mathrm{new}}(x)=\log\alpha+
\frac{1-\max_j\cos(x,c_j)}{\tau_{\mathrm{new}}},
\]
assigns by the largest existing-or-new score, and routes over existing clusters.
An empty route in either router falls back to namespace-local dense retrieval.

\section{GateMem Routing, Scoring, and Prediction}
\label{app:gatemem}

G0 is the exact upstream \texttt{rag\_naive} global TF--IDF route and G1 is the
upstream \texttt{rag\_policy} route with released policy logic.  G2 starts at the
authenticated asker, forms a connected component from explicit relationship IDs,
and admits chunks spoken by principals in that component; it reads neither query or
memory text nor leak targets when deciding support.  G3 adds only explicit pre-query
delete or supersede operations.  Because the release contains none, G3 is
trace-identical to G2.  G0 and G1 are upstream methods; G2 and G3 are diagnostics.

Each reader prompt contains the question and ordered retrieved record IDs and texts,
but not the arm name, scores, target strings, expected action, or gold answer.  Both
readers use temperature zero, JSON mode, and at most 384 output tokens.  The runs are
fresh, with no judge or output repair.  A strict parser accepts one object containing
action, answer, structured answer, and a string-list audit field; the audit field is
not scored, and parse failures receive conservative outcomes.

Privacy checkpoints use the released privacy context-leak and answer-leak rules;

over-refusal are bounded rule-based auxiliary outcomes rather than LLM-judge scores.

The incremental predictor is logistic regression with $C=1$, the \texttt{lbfgs}
solver, and at most 2,000 iterations.  Categorical features are arm, domain, and
query type; additional baseline features are route non-emptiness and standardized
route width.  The augmented model adds only target exposure.  Each held-out episode
is scored by a model fit on all other episodes.  Brier and log-loss differences are
then resampled over episodes with 10,000 deterministic bootstrap replicates.

\section{Controlled Exposure Construction}
\label{app:paired-construction}

Each of the 16 scenarios has two paraphrased query pairs, allow and block conditions,
and three manipulated roles: a relevant focal candidate, an irrelevant-admissible
candidate, and an irrelevant-inadmissible candidate.  The focal candidate is
admissible under allow and inadmissible under block.  For every
query--condition--candidate unit, two requests differ only in whether that candidate
is exposed.  This yields 192 paired units and 384 requests for each reader.

Every candidate carries a unique literal marker absent from the query and all other
candidates.  The normalized-substring scorer counts the marker even inside a refusal;
appearance after withholding is hallucinated disclosure.  Requests are stateless and
deterministically interleaved.  The original GPT, Gemini, and DeepSeek readers and the
separately executed Claude Opus 5 replication each complete all 384 requests with one
attempt per request.  There is no transport retry, judge, output repair, selective
rerun, or model pooling.  The released result packages contain only content-free pair
scores, aggregates, hashes, costs, and bootstrap intervals.
